# Критерії оцінювання результатів навчання учнів з фізики — 10–11 класи

Статичний вебзастосунок для GitHub Pages на основі наданого документа:
**«Критерії оцінювання для 10-11 класів (№1222 від 2013)»**.

## Що робить програма

1. Обирається рівень навчальних досягнень: Початковий, Середній, Достатній або Високий.
2. Обирається бал від 1 до 12 у межах відповідного рівня.
3. Відображається характеристика навчальних досягнень для цього бала.
4. Характеристика додається до картки учня.
5. У картку вводяться прізвище та ім'я.
6. Картку можна завантажити як SVG (відкривається у браузері та масштабуються без втрати якості) або надрукувати / зберегти через браузер як PDF.
7. Програма не використовує зовнішні JavaScript-бібліотеки або CDN.

## Публікація на GitHub Pages

Завантажте `index.html` у корінь репозиторію GitHub.

Далі:
**Settings → Pages → Deploy from a branch → main → / (root) → Save.**

## Важливо

Формулювання характеристик у програмі взяті з наданого документа без редакторського «покращення» формулювань. Це зроблено навмисно, щоб інструмент відповідав джерелу.
